# TTY1 Mobile React

Expo / React Native mobile client for TTY1.

This is the new mobile implementation aimed at a Happy Coder style reading experience:

- active terminal list with running/waiting status
- pairing by 6-digit desktop code
- automatic mobile identity registration
- WebSocket session sync with the existing TTY1 server
- reader-first session view with structured message/tool/code blocks
- raw terminal transcript fallback
- bottom composer for Codex-style prompts and shell commands

## Run

Use Node 22 LTS for the current Expo / React Native toolchain.

```powershell
cd mobile-react
npm install
npm run android
```

The app defaults to:

```text
wss://8.153.163.104:7373/ws
```

Open the pairing sheet, enter the 6-digit code generated by the desktop app, then connect.

## Migration Notes

The existing `mobile-android` Compose app is still kept intact while this client is validated.
Once the React Native client is feature complete, it can replace the Android release pipeline by
adding an Expo prebuild/EAS build flow or by generating the native Android project from Expo.
